# c01-d20-simple

Baseline: a single-column d20 table, each row one line. The number and the result are drawn as separate positioned
strings (the number right-aligned in its own column, the result 16 pt to the right), with zebra shading behind every
other row, the way most RPG layout programs export a table. Content stream order = reading order.
Exercises: basic row recognition, the gap between the number and result cells, digits inside result text ("10 gp").
